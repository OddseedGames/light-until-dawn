# Разработка и проверки

## Устройство проекта

`src/game.rs` содержит независимую от движка симуляцию: режим сложности, ресурсы, погоду, движение оператора, подбор и доставку топлива, выносливость, атаки и исходы партии. Модель не читает клавиатуру и не рисует. Её можно проверять без браузера и графического контекста.

`src/main.rs` получает ввод, переводит клавиши или маршрут от клика в `Controls`, вызывает модель и рисует сцену через Macroquad. Он также управляет звуком. Направление `Controls.direction`: +1 — в лес, −1 — к станции, 0 — стоять. Позиция модели нормирована от 0 (дверь) до 1 (дальний тайник). В сцене ей соответствует `x = 755 - position * 620`.

`Game::advance_with_controls` разбивает время на шаги не более 0,05 с. Главный цикл ограничивает время кадра до 0,1 с, чтобы зависание вкладки не проигрывало всю ночь сразу. `Game::advance` — тот же расчёт без движения. Модель использует детерминированные погоду и угрозу, без случайного генератора.

`web/` содержит HTML/CSS и браузерный мост Macroquad/Miniquad для WebGL, ввода и звука. Собственный JS скрывает загрузчик, ставит игру на паузу при потере фокуса и обновляет скрытый текстовый статус. В нём нет правил игры. Rust компилируется в WebAssembly; это не транспиляция игры в JavaScript.

Скрытый `#game-status` предоставляет фазу, ресурсы, позицию, остаток времени снаружи, груз, выносливость, режим и число канистр. Это позволяет читать состояние в браузерных проверках без функций, изменяющих игру извне. Статус обновляется четыре раза в секунду активной партии и при изменении фазы или режима.

## Сборка

Нужны Rust с целью `wasm32-unknown-unknown` и Python 3. В этой рабочей папке скрипты автоматически подхватывают Rust из `../.tools`; иначе используют `cargo` из PATH. Скрипты `.sh` запускаются в macOS/Linux либо совместимой shell.

```sh
rustup target add wasm32-unknown-unknown
./scripts/check.sh
./scripts/build.sh
```

После сборки:

- `dist/index.html` и соседние файлы — статическая версия для хостинга.
- `dist/play.html` — один автономный HTML с WASM, JS, шрифтом и встроенными в WASM звуками.
- `dist/OddseedGames-LightUntilDawn.zip` — HTML, инструкция игроку и лицензии для пересылки.

`scripts/package.py` упаковывает уже собранный `dist/`; для изменений Rust сначала запускай `build.sh`. `scripts/verify-package.py` проверяет отсутствие внешних ресурсов HTML/CSS, заголовок и содержимое встроенного WASM, целостность ZIP и наличие документов. Проверка входит в `build.sh`.

Для разработки можно использовать `./scripts/dev.sh`: сборка и локальный сервер на `127.0.0.1:8027`. Для готового `play.html` сервер не нужен.

## Автоматические тесты

`./scripts/check.sh` выполняет форматирование в режиме проверки, `cargo test --all-targets --locked` и проверку компиляции WASM. Игровые сценарии находятся в `tests/gameplay.rs`.

Проверяются пауза и рестарт; все виды поражения; ручной маршрут с подбором и доставкой; отсутствие автоматической выдачи топлива; возврат без груза; три канистры и отдых; блокировка действий вне станции; скорость, шум и выносливость; условия ремонта; выбор сложности; невалидное время; согласованность разных размеров шага.

Два сценария проходят целую ночь на каждом уровне: выживание без радио и раннее спасение. Контроллер использует только обычные действия модели, движение, подбор, переключение систем и ремонт. Он не пополняет ресурсы и не меняет время или позицию напрямую. Стратегия экономит отопление, чередует свет по уровню угрозы и переносит настоящие канистры.

## Проверка браузера перед отправкой

1. Распакуй ZIP в новую папку и открой её `play.html` по `file://`.
2. Отключи сеть в инструментах браузера и проверь запуск, звук и отсутствие ошибок консоли.
3. Выбери все режимы. Убедись, что начальные запасы и лимит вылазки меняются.
4. Пройди вылазку клавишами A/D, Shift и E; повтори кликами или касаниями.
5. Проверь: груз сам не заправляется, устройства снаружи заблокированы, вход отменяет таймер.
6. Проверь паузу во время вылазки, продолжение, рестарт, проигрыш по таймеру и отсутствие горизонтальной прокрутки на небольшом экране.

Автоматические сценарии подтверждают работу модели, но не графику, доступность, браузерные ограничения звука или совместимость конкретной ОС. Запуск на Windows отдельно не проверялся.

## CI и публикация

Workflow `.github/workflows/ci.yml` запускается при push в `main`, в pull request и вручную через GitHub Actions.

1. На Linux и Windows проверяются форматирование, все Rust-тесты и компиляция WASM. Версия Rust и необходимые компоненты закреплены в `rust-toolchain.toml`.
2. После проверок Linux собирает игру, автономный HTML и ZIP, проверяет упаковку и запускает браузерные тесты из `tests/browser/test_offline.py`.
3. Браузерные тесты открывают `file://` в Chromium с отключённой сетью: проверяют загрузку без внешних запросов, выбор режима, рестарт и полный маршрут с бегом, подбором топлива, паузой и возвращением. Ошибки JavaScript или WebGL в консоли приводят к падению теста. При ошибке CI сохраняет скриншоты и Playwright trace в артефакт `browser-diagnostics`.
4. Готовые HTML и ZIP сохраняются в артефакт `light-until-dawn-offline` на 30 дней. Для `main` после всех проверок выполняется деплой в окружение `github-pages`; pull request сайт не обновляет.

Постоянный адрес: <https://oddseedgames.github.io/light-until-dawn/>.

ZIP для друга: <https://oddseedgames.github.io/light-until-dawn/OddseedGames-LightUntilDawn.zip>.

В настройках репозитория `Settings -> Pages -> Build and deployment` выбран источник `GitHub Actions`. Деплой использует штатный `GITHUB_TOKEN`, разрешения `pages: write` и `id-token: write`; отдельные секреты и токены не нужны. Публикуется только содержимое собранного `dist/`.

Для отдельного запуска браузерных тестов после сборки:

```sh
python3 -m pip install -r tests/browser/requirements.txt
python3 -m playwright install --with-deps chromium
python3 -m unittest discover -s tests/browser -v
```

В CI Chromium использует программный рендеринг SwiftShader, поэтому графическая карта и X-сервер не нужны. Проверки Rust на Windows подтверждают компиляцию и модель; запуск браузерной игры на Windows этим workflow отдельно не проверяется.
