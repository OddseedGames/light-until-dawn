# Свет до рассвета · OddseedGames

[![CI and Pages](https://github.com/OddseedGames/light-until-dawn/actions/workflows/ci.yml/badge.svg)](https://github.com/OddseedGames/light-until-dawn/actions/workflows/ci.yml)

**[Играть в браузере](https://oddseedgames.github.io/light-until-dawn/)** · **[Скачать ZIP для игры без интернета](https://oddseedgames.github.io/light-until-dawn/OddseedGames-LightUntilDawn.zip)**

Браузерная игра на Rust + Macroquad: управляй ночной станцией, выходи за топливом и переживи три минуты до рассвета либо вызови спасателей по радио. Три уровня сложности, ручные вылазки, бег с выносливостью, метели и ограниченное топливо.

## Играть и отправить другу

Распакуй `dist/OddseedGames-LightUntilDawn.zip` и открой `play.html` двойным щелчком в браузере. Сервер, интернет, Rust и установка дополнительных программ не нужны. Проверено в настольном Chrome; Windows отдельно не проверялся.

Самостоятельный `dist/play.html` тоже запускается напрямую. WASM, загрузчик, шрифт и звуки находятся внутри файла. ZIP дополнительно содержит инструкцию и лицензии.

## Управление

| Ввод | Действие |
| --- | --- |
| Q перед партией | Выбрать сложность: Знакомство / Ночь / Кошмар |
| Enter | Начать или продолжить |
| 1 / 2 / 3 | Свет / отопление / радио, пока оператор на станции |
| E | Выйти, взять канистру рядом с ней, войти у двери |
| A / D или стрелки | Идти в лес / к станции |
| Shift | Бежать с расходом выносливости и дополнительным шумом |
| F | Укрепить периметр за топливо |
| P / Escape | Пауза |
| M | Звук, изначально выключен |
| R из паузы или после завершения | Новая партия в том же режиме |

Все действия доступны кнопками мышью и касанием. Снаружи можно идти кликом по сцене или кнопками «В лес» / «К дому»; кнопка «Бег» переключает бег. Для топлива нужно дойти до канистры, забрать её и вернуться к двери до конца таймера. Топливо выдаётся после входа. Всего три канистры; следующие расположены дальше.

Правила и параметры режимов: [docs/GAMEPLAY.md](docs/GAMEPLAY.md). Инструкция для получателя архива: [docs/QUICKSTART.txt](docs/QUICKSTART.txt).

## Сборка и тесты

Нужны Rust с целью `wasm32-unknown-unknown` и Python 3. Скрипты автоматически используют локальный Rust из `../.tools`, если он установлен; иначе — `cargo` из PATH.

```sh
rustup target add wasm32-unknown-unknown
./scripts/check.sh
./scripts/build.sh
```

`check.sh` проверяет форматирование, запускает тесты всех целей и проверяет компиляцию WASM. `build.sh` создаёт браузерную сборку, автономный HTML и ZIP, затем проверяет их целостность и встроенные ресурсы. Автотесты находятся в [tests/gameplay.rs](tests/gameplay.rs); среди них полное прохождение до рассвета и радиоспасения на всех трёх уровнях сложности.

GitHub Actions запускает Rust-проверки на Linux и Windows, собирает WASM и проверяет автономный HTML в Chromium с отключённой сетью. После успешных проверок ветка `main` автоматически публикуется в GitHub Pages. Для pull request выполняются проверки и сборка без публикации. Версия Rust закреплена в `rust-toolchain.toml`.

Для разработки с сервером: `./scripts/dev.sh`, адрес `http://127.0.0.1:8027`. Готовая игра сервера не требует.

Архитектура, роли Rust/WASM/JS, команды и порядок браузерных проверок: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Исходники

- `src/game.rs` — модель ресурсов, угроз, погоды, сложности и движения.
- `src/main.rs` — отрисовка, клавиатура, маршруты кликом и звук.
- `tests/gameplay.rs` — сценарии модели без графического окружения.
- `web/` — браузерная оболочка и мост движка к WebGL, вводу и звуку.
- `assets/` — шрифт и оригинальные синтезированные звуки.
- `scripts/` — проверки, сборка и упаковка.

Игровая логика и отрисовка написаны на Rust. В браузере выполняется скомпилированный WebAssembly. JavaScript загружает его и связывает с браузером; игровых правил в нём нет.
